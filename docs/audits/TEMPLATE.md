# تقرير مجلس التدقيق: اسم الوظيفة أو التغيير

- **التاريخ:** `YYYY-MM-DD`
- **توقيت الإصدار:** `YYYY-MM-DDTHH:MM:SS+04:00`
- **مفهوم الوظيفة:** `FC-NNN vX.Y`
- **حالة اعتماد المفهوم:** `APPROVED | ...`
- **بصمة مفهوم الوظيفة:** `SHA-256`
- **مرجع اعتماد المالك:** رسالة أو مادة `MoCh` محددة
- **المرحلة:** `CONCEPT | DESIGN | BUILD | HANDOFF`
- **نطاق التغيير:** وصف موجز
- **لقطة التغيير:** commit SHA أو قائمة ملفات/قطع أثرية وبصماتها
- **قرار المجلس:** `AWAITING_OWNER_CONCEPT_APPROVAL | REWORK_REQUIRED | READY_FOR_OWNER_TRIAL`
