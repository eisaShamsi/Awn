# ADR-003: بوابة النماذج وOpenAI Responses API

- **الحالة:** مقبول
- **التاريخ:** 2026-08-23

## السياق

يحتاج عَوْن إلى نموذج يفهم العربية ويعيد مخرجات منظمة ويقترح استدعاءات أدوات. ربط منطق المجال مباشرة بمزود أو نموذج محدد سيجعل الاختبار والترقية أصعب.

## القرار

- استخدام OpenAI Responses API كبوابة النموذج الأولى عبر حزمة Python الرسمية.
- وضعها خلف عقد داخلي `ModelGateway` يمكن استبداله بمزود وهمي أو مزود آخر.
- اختيار اسم النموذج من الإعداد `AWN_OPENAI_MODEL` بدل تضمينه في منطق المجال.
- استخدام مخرجات منظمة عندما ينتج النموذج خطة أو قرارًا قابلًا للتنفيذ.
- تعيين `store=false` افتراضيًا في استدعاءات النموذج، وتخزين السياق المطلوب داخل عَوْن وفق سياسة الذاكرة.
- لا ينفذ النموذج أثرًا خارجيًا مباشرة؛ يعيد نية أو استدعاء أداة يمر عبر سجل الأدوات ومحرك السياسات.
- يحدد التطبيق سقفًا للمخرجات والاستدعاءات والمدة والتكلفة لكل تشغيل.

## النتائج

- يمكن اختبار النواة بلا مفتاح API باستخدام بوابة وهمية.
- تظل ترقية النموذج تغيير إعداد واختبارات تقييم، لا إعادة تصميم للمجال.
- يتحمل التطبيق مسؤولية دورة الأدوات والموافقات وحفظ السياق.
