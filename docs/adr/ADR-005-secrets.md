# ADR-005: إدارة الأسرار والاتصالات

- **الحالة:** مقبول
- **التاريخ:** 2026-08-23

## السياق

سيستخدم عَوْن مفاتيح API ورموز OAuth ذات أثر مباشر في حسابات المستخدم. تسربها إلى قاعدة البيانات أو السجل أو النموذج خطر جوهري.

## القرار

- استخدام ملف `.env` غير متتبع ومتغيرات البيئة في التطوير المحلي.
- استخدام مخزن أسرار مُدار في التشغيل الخاص أو الإنتاجي.
- تخزين مرجع السر `secret_ref` ونطاقاته وحالته فقط في قاعدة البيانات.
- منع تمرير السر إلى النموذج أو الواجهة أو سجل التدقيق.
- دعم تدوير السر وسحبه وتعطيل الاتصال دون حذف سجل التدقيق.
- إخفاء الحقول الحساسة وفق عقد كل أداة قبل التسجيل.

## النتائج

- يحتاج التشغيل المحلي إلى خطوة إعداد واضحة لكنه لا يعرّض الأسرار للمستودع.
- تصبح المهايئات مسؤولة عن طلب السر وقت التنفيذ فقط.
- يجب اختبار التنقيح والتسرب كجزء من CI الأمني.
