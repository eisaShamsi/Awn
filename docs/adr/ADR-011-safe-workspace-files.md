# ADR-011: حدود ملفات مساحة العمل الآمنة

- **الحالة:** مقبول
- **التاريخ:** 2026-08-23

## السياق

إنشاء ملف قدرة داخلية مفيدة، لكنه يفتح خطر اجتياز المسار أو الكتابة فوق ملف للمستخدم أو اتباع رابط رمزي إلى خارج النطاق. لا يكفي فحص النص بحثًا عن `..` بعد الوصول إلى نظام الملفات.

## القرار

- تعمل `files.create` داخل جذر يضبطه المشغل بواسطة `AWN_WORKSPACE_FILES_ROOT`، وتملك كل مساحة عمل مجلدًا باسم معرفها UUID.
- يقبل عقد الأداة مسارًا نسبيًا بنمط `/` فقط. تُرفض المسارات المطلقة، وأحرف Windows المحجوزة، والأجزاء الفارغة أو `.` أو `..`، والروابط الرمزية.
- يُحل المسار بعد إنشاء كل مجلد وسيط ويُتحقق أنه ما زال داخل جذر مساحة العمل.
- تنشئ الأداة ملف UTF-8 جديدًا عبر ملف مؤقت خاص باستدعاء الأداة ثم رابط ذري لا يستبدل هدفًا موجودًا.
- إذا أعيد الاستدعاء ووجد ملف مطابق المحتوى، تعاد النتيجة نفسها بوصفها استعادة آمنة. إذا اختلف المحتوى، يفشل الاستدعاء ولا يستبدل الملف.
- لا تعيد نتيجة الأداة مسار الجهاز المطلق؛ تعرض المسار النسبي والحجم وبصمة SHA-256 فقط.

## النتائج

- لا تمنح مدخلات النموذج صلاحية اختيار مسار عشوائي على الجهاز.
- يمكن استعادة التنفيذ بعد انقطاع وقع عقب إنشاء الملف من دون نسخه أو استبداله.
- تعديل ملف موجود وحذفه ونقل ملفات المشروع ليست ضمن هذه الأداة، وستحتاج عقودًا ومخاطر وموافقات مستقلة.
