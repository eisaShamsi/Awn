# ADR-001: منصة الخادم ونمط التطبيق

- **الحالة:** مقبول
- **التاريخ:** 2026-08-23

## السياق

يحتاج عَوْن إلى API مكتوبة الأنواع، ونماذج تحقق صارمة، ودعم جيد للذكاء الاصطناعي والأعمال الخلفية، من دون عبء خدمات موزعة في الإصدار الأول.

## القرار

- استخدام Python `3.12+` لغةً أساسية للخادم والعامل الخلفي.
- استخدام FastAPI لواجهة HTTP وPydantic للعقود والإعدادات.
- استخدام SQLAlchemy وAlembic للوصول إلى البيانات وترحيلها.
- استخدام PostgreSQL مصدرًا دائمًا للحقيقة.
- بناء النظام كتطبيق موحّد مقسّم إلى وحدات: `domain`, `application`, `agent`, `policy`, `tools`, `memory`, و`infrastructure`.
- منع استيراد تفاصيل البنية التحتية من طبقة المجال.

## النتائج

- تصبح البداية والتشغيل والاختبار أبسط من منظومة الخدمات المصغرة.
- يمكن فصل العامل أو التكاملات لاحقًا عبر حدود الوحدات.
- يجب مراقبة الاعتماديات ومنع انتشار نماذج إطار الويب داخل المجال.
