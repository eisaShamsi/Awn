# سجل القرارات المعمارية

يسجل هذا المجلد القرارات التقنية المؤثرة في عَوْن، والسياق الذي أدى إليها، والآثار المترتبة عليها. القرار المقبول لا يتغير نصه لإخفاء التاريخ؛ إذا تغيرت الحاجة، يُنشأ ADR جديد يلغي القرار السابق أو يعدله.

| [ADR-002](ADR-002-web-interface.md) | واجهة الويب وبروتوكولات الاتصال | مقبول |
| [ADR-003](ADR-003-model-gateway.md) | بوابة النماذج وOpenAI Responses API | مقبول |

| [ADR-006](ADR-006-first-integration.md) | GitHub بوصفه أول تكامل خارجي | مقبول |
| [ADR-007](ADR-007-memory-policy.md) | الذاكرة والاحتفاظ والحذف | مقبول |

| [ADR-009](ADR-009-tool-registry-execution.md) | سجل الأدوات والتنفيذ المصرح القابل للإعادة | مقبول |

## حالات القرار

- **مقترح:** قيد النقاش ولا يُبنى عليه التزام دائم.
- **مقبول:** معتمد ويجب أن يلتزم به التنفيذ.
- **ملغى:** استبدله قرار أحدث مع الإشارة إليه.
- **مرفوض:** نوقش ولم يُعتمد.
