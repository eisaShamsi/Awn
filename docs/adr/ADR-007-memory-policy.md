# ADR-007: الذاكرة والاحتفاظ والحذف

- **الحالة:** مقبول
- **التاريخ:** 2026-08-23

## السياق

تضيف الذاكرة قيمة شخصية كبيرة، لكنها قد تنشر معلومة خاطئة أو حساسة عبر مهام مختلفة إذا حُفظت أو استرجعت بلا حدود واضحة.

## القرار

- لا تصبح المعلومة ذاكرة طويلة المدى إلا بموافقة المستخدم أو إجراء إعداد صريح منه.
- تحمل كل ذاكرة مصدرًا ونطاقًا وحساسية ودرجة ثقة وتاريخ إنشاء وصلاحية اختيارية.
- استخدام بحث PostgreSQL النصي والمرشحات الحتمية في البداية.
- تأجيل embeddings والبحث الدلالي حتى يثبت تقييم مقارن أنه يحسن الاسترجاع.
- الاحتفاظ بالمحادثات محليًا حتى يحذفها المستخدم في `v0.1`، مع توفير إعداد مدة تلقائية قبل الإنتاج.
- الاحتفاظ بسجل التدقيق 90 يومًا افتراضيًا مع تنقيح المحتوى الحساس، وإتاحة تعديل المدة.
- يمنع حذف الذاكرة استرجاعها فورًا، ثم تحذف من النسخ الاحتياطية وفق دورة الاحتفاظ المعلنة.

## النتائج

- يظل سلوك الذاكرة مفهومًا وقابلًا للمراجعة.
- يتطلب حفظ الذاكرة تفاعلًا إضافيًا في البداية.
- يجب قياس جودة الاسترجاع قبل إضافة بنية متجهية وتعقيدها.
