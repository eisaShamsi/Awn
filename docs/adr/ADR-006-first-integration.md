# ADR-006: GitHub بوصفه أول تكامل خارجي

- **الحالة:** مقبول
- **التاريخ:** 2026-08-23

## السياق

يجب أن يثبت أول تكامل دورة «خطط، استأذن، نفّذ، تحقق» في مجال مفيد للمستخدم وقابل للاختبار، مع مخاطر أقل من إرسال البريد أو تعديل التقويم الشخصي.

## القرار

- اعتماد GitHub أول تكامل خارجي لعَوْن.
- يبدأ النطاق بقراءة المستودعات وIssues وPull Requests المصرح بها.
- يسمح بإنشاء Issue أو مسودة Pull Request بعد معاينة وموافقة صريحة.
- يؤجل دمج Pull Request، حذف الموارد، تغيير الصلاحيات، والدفع القسري إلى ما بعد `v0.1`.
- تستخدم صلاحيات دقيقة ومستودعات مسموحة صراحة، مع إمكانية فصل الاتصال فورًا.

## النتائج

- يمكن إثبات القيمة داخل مشروع عَوْن نفسه وتوثيق دليل التنفيذ بمعرف GitHub.
- لا يغطي التكامل الأول وظائف السكرتارية الزمنية؛ يأتي التقويم بعد نجاح دورة التنفيذ.
- يجب معاملة محتوى Issues والملفات كبيانات غير موثوقة لا كتعليمات للنظام.
