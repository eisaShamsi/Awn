# نموذج التهديد وسياسة بيانات عَوْن

- **الإصدار:** 1.0
- **التاريخ:** 2026-08-23
- **النطاق:** النواة المحلية والامتدادات المخططة حتى `v0.1`
- **المالك:** مستخدم عَوْن

## 1. الهدف والافتراضات

تحمي هذه الوثيقة سرية بيانات المستخدم، وسلامة قرارات عَوْن وآثاره، وقدرته على تفسير ما فعله. النسخة الحالية مخصصة لمستخدم واحد على جهاز موثوق، وتربط خدمتي الويب وAPI على `127.0.0.1`. لا تعد المصادقة المحلية بديلًا عن مصادقة حقيقية إذا أصبح التطبيق متاحًا عبر شبكة.

نفترض أن نظام التشغيل وحساب المستخدم وقاعدة PostgreSQL المحلية محدثة ومحمية. ولا نفترض أن محتوى الرسائل أو الويب أو البريد أو الملفات أو مخرجات النماذج موثوق؛ كلها مدخلات قد تحتوي تعليمات خبيثة.

## 2. الأصول وحدود الثقة

### الأصول التي يجب حمايتها

- المحادثات والمهام والخطط والذاكرة والتفضيلات.
- أسرار مزودي النماذج والتكاملات المستقبلية.
- موافقات المستخدم وسياسات التفويض وبصمات الإجراءات.
- سجل التدقيق وأدلة نجاح التنفيذ أو فشله.
- سلامة ملفات مساحة العمل والموارد الخارجية التي قد يعدلها عَوْن.

### حدود الثقة

1. **المتصفح ↔ BFF في Next.js:** مدخلات المستخدم والهوية المحلية.
2. **BFF ↔ API:** الطلبات المقيدة بالمستخدم ومساحة العمل.
3. **API ↔ PostgreSQL:** مصدر الحقيقة الدائم والحالات والمعاملات.
4. **المنسق ↔ مزود النموذج:** سياق محدود ومخرجات منظمة غير موثوقة حتى التحقق.
5. **محرك السياسات ↔ الأدوات:** الحد الفاصل قبل أي أثر جانبي.
6. **الأدوات ↔ الخدمات أو الملفات الخارجية:** بيانات وصلاحيات خارج سيطرة عَوْن المباشرة.

## 3. تصنيف البيانات والاحتفاظ

| الفئة | أمثلة | الحساسية | سبب التخزين | الاحتفاظ الافتراضي | الحذف أو التنقيح |
|---|---|---:|---|---|---|
| الهوية المحلية | المستخدم ومساحة العمل | داخلية | عزل الملكية والنطاق | حتى حذف الحساب | حذف مترابط بعد التحقق من الملكية |
| محتوى العمل | المحادثات والرسائل والمهام والخطط | سرية | الاستمرارية والسياق والتتبع | محليًا حتى يحذفها المستخدم في `v0.1` | يجب توفير حذف وتصدير قبل الإصدار الخاص |
| حالة التشغيل | الحالات والأخطاء ونتائج التحقق | داخلية، وقد تصبح سرية | الاستئناف والتشخيص ومنع الادعاء الكاذب بالنجاح | مع موردها الأصلي | تنقيح الأسرار؛ حذفها مع المورد وفق السياسة |
| الموافقات | القرار والنطاق والبصمة والانتهاء | سرية | إثبات الإذن ومنع تبديل الإجراء | ضمن سجل التدقيق | لا يعاد استخدامها بعد الانتهاء أو تغير البصمة |
| سجل التدقيق | قرارات السياسة واستدعاءات الأدوات | سرية | المساءلة والتحقيق | 90 يومًا افتراضيًا | محتوى منقح، والمدة قابلة للضبط |
| الذاكرة المعتمدة | تفضيلات وحقائق وافق المستخدم عليها | سرية | التخصيص طويل المدى | حتى الحذف أو انتهاء الصلاحية | يوقف الحذف الاسترجاع فورًا |
| الأسرار | مفاتيح API ورموز OAuth | شديدة السرية | الاتصال بالمزود فقط | حتى السحب أو التدوير | لا تدخل قاعدة المحتوى أو السجلات؛ تمحى عند الفصل |
| بيانات النموذج | الحد الأدنى من سياق الطلب | بحسب المصدر | توليد جواب أو خطة | لا يطلب عَوْن من المزود الاحتفاظ بها؛ `store=false` | لا تُرسل الأسرار أو سياقات غير لازمة |

تفاصيل الذاكرة ودورة النسخ الاحتياطية يحكمها [ADR-007](adr/ADR-007-memory-policy.md). وحتى اكتمال واجهات الحذف والتصدير، تبقى النسخة المحلية **نسخة تطوير** وليست إصدار `v0.1` مكتملًا.

## 5. قواعد أمنية غير قابلة للتجاوز

1. لا تنفذ مخرجات النموذج مباشرة؛ تتحقق بنيويًا ثم تمر عبر محرك السياسات.
2. لا تعد الموافقة صالحة إلا للعملية والموارد والمدخلات التي تغطيها بصمتها.
3. كل أثر مرتفع المخاطر يحتاج موافقة صريحة حديثة، ولا تكفي موافقة عامة مبهمة.
4. لا تفسر بيانات خارجية بوصفها أوامر نظام، ولا تمنح النموذج أسرار الأدوات.
5. لا يعلن التشغيل نجاحه قبل التحقق من الأثر؛ ويعرض النجاح الجزئي أو الفشل كما حدث.
6. كل قراءة أو تعديل دائم مقيد بالمستخدم ومساحة العمل.
7. يسجل التدقيق القرارات والنتائج بعد تنقيح الأسرار، لا المحتوى الحساس كاملًا بلا حاجة.
8. الإعداد الافتراضي لأي قدرة جديدة هو المنع أو طلب الموافقة حتى توثق صلاحياتها ومخاطرها.

## 6. التحقق وبوابات الإصدار

- تختبر محاولات تجاوز الموافقة، وتغيير المدخلات بعد الموافقة، وتكرار الطلب، وحقن الأوامر.
- تختبر عزلة مساحات العمل وحذف الذاكرة ومنع ظهور القيم السرية في السجلات.
- يراجع نطاق كل تكامل وصلاحياته قبل تفعيله، مع مسار فصل وسحب فوري.
- لا ينشر التطبيق على شبكة قبل إضافة المصادقة وحماية الجلسة وCSRF وضبط CORS والوكيل العكسي.
- لا يصدر `v0.1` قبل نجاح النسخ الاحتياطي والاستعادة والتصدير والحذف ومراجعة ثغرات حرجة.

## 7. المخاطر المتبقية حاليًا

- النسخة المحلية تعتمد على أمان حساب Windows والجهاز، ولا تحتوي مصادقة متعددة المستخدمين.
- حذف البيانات وتصديرها والنسخ الاحتياطي المشفر لم تكتمل بعد.
- سجل التدقيق الدائم ومنفذ الأدوات الآمن واستهلاك الموافقة ذريًا من مخرجات المرحلة 2.
- إرسال السياق إلى مزود نموذج خارجي اختياري؛ وعلى المستخدم اختيار المزود وفق حساسية بياناته.

تُراجع هذه الوثيقة عند إضافة أداة أو تكامل أو نوع بيانات أو حدود نشر جديدة، ويُوثق التغيير المؤثر في ADR عند الحاجة.
